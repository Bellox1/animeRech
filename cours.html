VLAN

Version simple non détaillée : Un VLAN est un réseau virtuel à l’intérieur d’un switch.

Version simple détaillée : Un VLAN (Virtual Local Area Network) permet de séparer logiquement un réseau en plusieurs groupes indépendants, même s’ils sont sur le même switch. Cela améliore la sécurité et l'organisation du réseau.

Trunk

Version simple non détaillée : Le Trunk permet de faire passer plusieurs VLAN sur un seul câble entre deux switchs.

Version simple détaillée : Un port Trunk est un port spécial configuré sur un switch pour transporter plusieurs VLAN à la fois vers un autre switch. Il utilise le protocole 802.1Q pour marquer les trames selon leur VLAN d’origine.

Port Security

Version simple non détaillée : C’est une sécurité pour limiter quels appareils peuvent se connecter à un port.

Version simple détaillée : Port Security permet de limiter le nombre d’appareils (en fonction de leur adresse MAC) pouvant se connecter à un port d’un switch. Si un appareil inconnu se connecte, le port peut être désactivé pour protéger le réseau.

VTP

Version simple non détaillée : VTP permet de synchroniser les VLAN entre plusieurs switchs.

Version simple détaillée : VTP (VLAN Trunking Protocol) est un protocole Cisco qui partage automatiquement les informations de VLAN (nom, ID) entre les switchs. Cela facilite la gestion centralisée des VLAN.

DTP

Version simple non détaillée : DTP négocie automatiquement si un port doit être en mode Trunk ou Access.

Version simple détaillée : DTP (Dynamic Trunking Protocol) permet aux switchs de décider automatiquement si un port doit être en mode Trunk ou Access. Il facilite l’autoconfiguration mais peut être désactivé pour des raisons de sécurité.

STP

Version simple non détaillée : STP évite les boucles dans un réseau avec plusieurs chemins.

Version simple détaillée : STP (Spanning Tree Protocol) désactive certains liens entre switchs pour empêcher les boucles réseau. Il garde un seul chemin actif, et active un autre lien en cas de panne, garantissant la stabilité du réseau.

DHCP

Version simple non détaillée : DHCP donne automatiquement une adresse IP aux machines.

Version simple détaillée : DHCP (Dynamic Host Configuration Protocol) attribue automatiquement une adresse IP, une passerelle et des DNS aux appareils sur un réseau, ce qui évite de les configurer manuellement.

EtherChannel

Version simple non détaillée : EtherChannel regroupe plusieurs câbles en un seul lien logique.

Version simple détaillée : EtherChannel combine plusieurs ports physiques d’un switch en un seul lien logique, augmentant la bande passante et assurant une tolérance aux pannes si un câble est défectueux.
